08

Notes on dates and versions

TopicNote
Identified dateThe first public date: researcher report (Chrome), leak (PHP), discovery (eMudhra) or vendor advisory. Most vendors don't publish the private discovery date.
Patch released dateThe date the stable fixed version was published. Tomcat's fixed versions were already out when the advisory came on 20 Oct. OVHcloud CLI 0.16.0's exact date was not confirmed.
LiteLLMNot a bug. Version 1.107.0 was malicious, so the fix is going back to 1.106.2, the last clean release.
Linux distrosUbuntu, Debian and RHEL often patch PHP and Java without changing the upstream version number. Check the distro's security tracker.
Vulnerable rangesRanges like "8.4.0 – 8.4.26" are derived from the fixed version: everything before the fix on that branch is vulnerable.
Not OctoberLeft out of this page: Plex2Shell (fixed Aug 2026), BeyondTrust (exploited since Aug 2026), Palo Alto GlobalProtect (May 2026). All three are still exploited and listed in the Threat Report.
Source dataVendor advisories and security reporting as of 23 Oct 2026. Check the vendor page before signing off a patch.
